4 Manfaat Pancasila sebagai Dasar Negara
🧭

1. Pedoman Hidup

Pedoman dalam pengambilan keputusan dan pemecahan masalah dalam kehidupan bermasyarakat, berbangsa, dan bernegara.

⚖️

2. Sumber Hukum

Sumber dari segala sumber hukum; seluruh peraturan di Indonesia tidak boleh bertentangan dengan nilai-nilai Pancasila.

🌟

3. Cita-Cita Bangsa

Tujuan dan cita-cita bangsa yang tercermin dalam nilai ketuhanan, kemanusiaan, persatuan, kerakyatan, dan keadilan.

🆔

4. Kepribadian Bangsa

Identitas bangsa Indonesia sehingga nilainya harus diterapkan oleh setiap warga dalam kehidupan sehari-hari.

Aplikasi PancaVenture 7 kini terhubung langsung ke Firebase Realtime Database menggunakan REST API (GET, PUT, PATCH, DELETE) berkecepatan tinggi tanpa antrean server, siap di-hosting di GitHub Pages untuk 30+ siswa secara bersamaan.

Endpoint Database Aktif:
https://micro-3b8a8-default-rtdb.asia-southeast1.firebasedatabase.app/pancaventure7/accounts.json
• PIN 4 angka siswa dienkripsi dengan SHA-256 + PEPPER sebelum disimpan.
• Kredensial Guru Utama diamankan dengan pencocokan hash SHA-256 (tidak tertulis kasatmata di kode sumber).

Konfigurasi Rules di Firebase Console: Buka Firebase Console > Realtime Database > Rules, pastikan aturan baca/tulis pada node pancaventure7 diizinkan seperti contoh di bawah, lalu klik Publish: 

{
  "rules": {
    "pancaventure7": {
      ".read": true,
      ".write": true
    }
  }
